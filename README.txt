NOTESCARRIER WORDPRESS THEME
============================

NotesCarrier is a responsive WordPress theme for study notes, book reviews,
competitive-exam resources, and learning blogs.

INSTALL
-------
1. In WordPress, open Appearance > Themes > Add New Theme > Upload Theme.
2. Upload notescarrier.zip and choose Install Now.
3. Activate NotesCarrier.

If NotesCarrier is already installed, upload this updated ZIP and choose the
option to replace the installed theme with the uploaded version.

You can also unzip the theme and upload the notescarrier folder to
wp-content/themes/ with your hosting file manager or SFTP.

FIRST SETUP
-----------
1. Open Appearance > Customize > Site Identity. Set the site title to
   "NotesCarrier" and add a short tagline.
2. Add a featured image to each post. The homepage and post lists use each
   article's featured image automatically.
3. Create and assign categories (for example Banking, Books PDF, SSC, and
   Exam Preparation). Topic links are generated from your actual categories.
4. Open Appearance > Menus. Create a navigation menu and assign it to
   "Primary Menu"; optionally assign a second menu to "Footer Menu".
5. To use a dedicated posts page, create a page called Blog, then open
   Settings > Reading and select it as the Posts page.
6. Confirm the existing category slug is "latest-notification". The newest
   published post in that category appears in the compact strip above the page
   content automatically.
7. Open Appearance > Customize > NotesCarrier Community Popup to change the
   social links or popup delay. The Telegram button defaults to
   https://t.me/notescarrier3. The popup stays dismissed for seven days after
   a visitor closes it.

FEATURES
--------
- WordPress-driven homepage, post archives, category pages, search, pages,
  and individual articles.
- Responsive navigation and layouts for desktop, tablet, and mobile.
- Featured post and latest-post feed on the homepage.
- Compact carousel of the five newest published Latest Notification posts (or
  fewer when fewer than five have been published in that category).
- Community popup with configurable Telegram and YouTube links.
- Up to five related book and study-resource posts beneath each article.
- Search/social metadata and BlogPosting structured data when no SEO plugin
  already supplies them.
- Single-row, touch-friendly pagination.
- Popular posts ranked by comment count, plus automatically populated topics.
- Accessible search, keyboard-friendly mobile menu, reduced-motion support,
  and screen-reader skip link.
- Supports custom logos, featured images, menus, block editor styles, comments,
  and standard WordPress post content.

The "Popular posts" list uses WordPress comment counts because WordPress does
not track page views by default. If you install an analytics or popular-posts
plugin later, its ranking can be connected separately.
